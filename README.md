
# سامانه رزرو آنلاین قصر پیرایش

## امکانات
- نمایش خدمات، قیمت‌ها و ساعات کاری
- انتخاب تاریخ و ساعت بر اساس مدت خدمت
- جلوگیری از رزرو هم‌زمان در یک بازه
- ثبت درخواست با وضعیت «در انتظار تأیید»
- پنل مدیر برای تأیید یا رد رزرو
- لینک تماس واتساپ با شماره اعلام‌شده

## راه‌اندازی روی کامپیوتر
نیازمندی: Node.js نسخه 18 یا جدیدتر

```bash
npm install
```

قبل از اجرا، متغیرهای محیطی را تنظیم کنید:
- `ADMIN_PASSWORD`: رمز ورود مدیر
- `ADMIN_TOKEN`: یک رشته محرمانه و طولانی برای دسترسی پنل
- `PORT`: اختیاری، پیش‌فرض 3000
- `DB_PATH`: اختیاری، مسیر فایل پایگاه داده

نمونه اجرا در Linux/macOS:
```bash
export ADMIN_PASSWORD='یک-رمز-قوی-و-منحصربه-فرد'
export ADMIN_TOKEN='یک-توکن-تصادفی-طولانی'
npm start
```

سپس سایت در `http://localhost:3000` و پنل مدیریت در `http://localhost:3000/admin.html` در دسترس است.

## انتشار اینترنتی
این پروژه به میزبانی Node.js نیاز دارد. هنگام انتخاب میزبان، مطمئن شوید فضای ذخیره‌سازی پایدار (persistent disk/volume) برای فایل `bookings.sqlite` فراهم می‌کند؛ در غیر این صورت ممکن است اطلاعات رزروها پس از راه‌اندازی مجدد از بین برود. متغیرهای محیطی بالا را در پنل میزبان تنظیم کنید.

## نکته‌های مهم پیش از انتشار
- رمز مدیر و توکن را حتماً تغییر دهید.
- برای اطلاع‌رسانی خودکار پیامکی یا واتساپی، باید سرویس پیام‌رسان و دسترسی API جداگانه راه‌اندازی شود. در نسخه فعلی، مشتری و مدیر از طریق لینک واتساپ می‌توانند گفتگو را باز کنند؛ ثبت رزرو داخل پایگاه داده انجام می‌شود.
- شماره تماس واتساپ در فایل `public/index.html` درج شده و در صورت تغییر باید به‌روزرسانی شود.
- تاریخ‌ها در این نسخه به صورت میلادی در ورودی تقویم مرورگر انتخاب می‌شوند.
